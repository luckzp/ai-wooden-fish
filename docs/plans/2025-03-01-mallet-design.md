# 木槌与敲击动画 — 设计说明

**目标：** 在木鱼旁新增木槌视觉，并在用户点击时播放木槌敲击动画，与现有敲击音效和功德逻辑保持一致。

**方案选择：** 在现有 `WoodenFish.vue` 内增加木槌（不拆成独立组件），保持“点击整块区域 = 敲一下”的交互，木槌动画与现有 `isTapping` 状态同步。

**布局：** 木鱼 + 木槌横向排列，木槌在右侧（符合右手持槌习惯）；用 flex 包裹，整体仍为一个可点击按钮。

**木槌形态：** 内联 SVG：槌头（圆角矩形/椭圆）+ 槌柄（细长矩形），配色与木鱼一致（如 `#702f00` / `#4a2000`），带相同风格的 drop-shadow。

**动画：** 点击时与 `isTapping` 同步（约 200ms）：木槌绕“握点”（槌柄末端或靠近木鱼的一侧）向下旋转约 25°–35° 做敲击，再回到初始角度；使用 `transform: rotate()` + `transform-origin`，用 CSS transition 或与现有 `.tap` 类同步的 class 控制。

**无障碍：** 不新增独立可聚焦控件，木槌视为装饰；保留当前按钮的 `aria-label="敲木鱼"`。

**涉及文件：**
- `src/components/WoodenFish.vue`：增加木槌 SVG、布局与敲击动画 class/样式。
