# 赛博寺 · 视觉/动效增强设计（方案 2）

> 用户已确认采用本设计。实现前请基于本文档制定并执行实现计划。

## 目标

在保持禅意、轻量、无新依赖的前提下，通过木鱼动效、功德气泡多样化与背景粒子氛围，提升「赛博寺」的趣味性与吸引力。

## 1. 木鱼动效

- **点击瞬间**：保留现有缩放（如 `scale(0.92)`），可增加 50–80ms 轻微「压下」感（如 `translateY(2px)`）。
- **涟漪/光晕**：在木鱼中心触发一圈自内向外扩散的圆环（CSS `::after` 或独立元素），半径约 0→80px，透明度 0.4→0，时长约 0.5s，不遮挡木鱼。
- **轻微 3D 倾斜（可选）**：点击时增加 `rotateX(2deg) rotateY(-2deg)`，约 0.15s 后回正，增强敲击反馈。
- **约束**：仅用 CSS `transform`/`opacity`，保证 60fps；不引入新依赖。

## 2. 功德气泡

- **文案与样式**：沿用 i18n，可增加 2～3 种短句轮换（如「功德+1」「善哉」「叮」），按语言随机展示。气泡随机 0.85～1.15 倍字号、85%～100% 不透明度，颜色在现有棕/金系内微调。
- **动效**：上升使用 `cubic-bezier(0.2, 0.8, 0.2, 1)`，约 1.2s 内上移 80～100px 并淡出；可选出现时 `scale(0.8)→1` 约 0.15s 弹出。
- **数量与性能**：保持现有最大数量与移除逻辑，避免 DOM 堆积。

## 3. 背景与氛围

- **粒子/光点**：低密度（约 20～40 个），在视口内缓慢随机漂移（2～5px/s 量级），透明度 0.15～0.35，颜色与当前主题一致（深色用浅黄/米色，浅色用深棕/灰）。
- **实现**：优先 CSS 动画（每粒子一 div + `@keyframes`），保证与现有 `radial-gradient` 融合；粒子层 `pointer-events: none`，`z-index` 低于主内容。
- **约束**：不替换现有背景，仅叠加一层粒子容器，保持安静、不抢焦点。

## 4. 技术约束与兼容

- **技术**：仅用 Vue 3 + CSS（`@keyframes`、`transform`、`opacity`），不引入新库。
- **无障碍**：动效不改变焦点与读屏；可选对 `prefers-reduced-motion: reduce` 减弱或关闭涟漪与粒子。
- **兼容**：目标为现代浏览器（与当前 Vite/Vue3 一致）；不支持时回退为当前静态样式。
